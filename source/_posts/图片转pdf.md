# 1.选择要生成 pdf 文件的图片，并单击右键，选择打印

![屏幕截图 2023-10-29 144555](https://charerchou-imgbed.oss-cn-beijing.aliyuncs.com/CharerChou-imgBed/zjhimgbed%E5%B1%8F%E5%B9%95%E6%88%AA%E5%9B%BE%202023-10-29%20144555.png)

# 2.打印机（R）选项设置为 Microsoft Print to PDF

![屏幕截图 2023-10-29 144618](https://charerchou-imgbed.oss-cn-beijing.aliyuncs.com/CharerChou-imgBed/zjhimgbed%E5%B1%8F%E5%B9%95%E6%88%AA%E5%9B%BE%202023-10-29%20144618.png)

# 3.点击右下角选项，并选择打印机属性![屏幕截图 2023-10-29 144637](https://charerchou-imgbed.oss-cn-beijing.aliyuncs.com/CharerChou-imgBed/zjhimgbed%E5%B1%8F%E5%B9%95%E6%88%AA%E5%9B%BE%202023-10-29%20144637.png)

# 4.在此处选择横向/纵向

![屏幕截图 2023-10-29 144659](https://charerchou-imgbed.oss-cn-beijing.aliyuncs.com/CharerChou-imgBed/zjhimgbed%E5%B1%8F%E5%B9%95%E6%88%AA%E5%9B%BE%202023-10-29%20144659.png)
