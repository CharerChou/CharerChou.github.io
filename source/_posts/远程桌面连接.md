# 1.家庭版 windows 开启远程桌面服务

win11 家庭版不提供远程桌面连接服务（只能连接其他设备，不能被其他设备连接），因此需要解决这个问题。以下是解决方法：

[家庭版 Windows11 开启远程桌面被控 - 知乎 (zhihu.com)](https://zhuanlan.zhihu.com/p/600706130#概览)（评论区有对应解决方案）

# 3.获取用户名

在 powershell 或者 cmd 中输入指令 whoami

出现的一串字符即为用户名，密码是 Microsoft 密码（非 PIN）

![屏幕截图 2023-11-10 235713](https://charerchou-imgbed.oss-cn-beijing.aliyuncs.com/CharerChou-imgBed/zjhimgbed%E5%B1%8F%E5%B9%95%E6%88%AA%E5%9B%BE%202023-11-10%20235713.png)

# 4.一些情况的解决方法

有时在客机断开连接后，主机出现卡在锁屏首页，无法进入第二屏输入密码的情况。此时按下 ctrl+alt+del，即可进入第二屏输入密码解锁屏幕。
